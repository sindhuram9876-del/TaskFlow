TaskFlow – Smart Task Manager

TaskFlow is a responsive and user-friendly task management web application designed to help users organize their daily activities, manage priorities, and track their progress.

Features

- Add, edit and delete tasks
- Mark tasks as completed or active
- Search tasks
- Filter tasks by status
- Manage task priorities
- Organize tasks by categories
- Set task due dates
- Calendar view
- Notification panel
- Dark and light themes
- Task export
- Clear completed tasks
- Responsive design for mobile, tablet and desktop
- LocalStorage support to save tasks in the browser

Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open "index.html" in your browser.
4. Start managing your tasks!

Purpose

This project was developed to practice frontend web development, JavaScript functionality, responsive UI design and browser-based data storage.
